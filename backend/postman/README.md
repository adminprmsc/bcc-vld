# Postman

Import **`LDS-API.postman_collection.json`** into Postman.

## Setup

1. Import collection (File → Import)
2. Set `baseUrl`:
   - Local backend: `http://localhost:3000`
   - Docker/nginx: `http://localhost/api`
3. Run **Users → Login** (saves `token` automatically)
4. Call other endpoints

Default login: `admin@lds.gov.pk` / `Admin@123`
